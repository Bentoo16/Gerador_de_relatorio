Aplicativo feito para gerar relatórios para a análise da qualidade em mamografia.

O usuário preenche a ficha avaliativa onde existe um banco de dados liago com as respostas dessa ficha. 
As respostas do banco de dados é enviado para a AI (Ollama_version_0.40.4) onde a AI organiza as frases de forma estruturada.
Esse banco de dados é feito com base em relatórios antigos.
Esse aplicativo gera um arquivo .docx para o usuário editar o que bem desejar. Nesse documento também é feita a ficha avaliativa para o usuário não se perder.
